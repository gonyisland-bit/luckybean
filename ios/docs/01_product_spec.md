# 01 · 제품 명세 — 화면과 흐름

시안 캔버스(6차 줄이 최신): https://claude.ai/artifact/4v4m25RLLZUkhQxu4psq1M
레퍼런스 PNG: `art/reference/` (아래 표의 파일명)

## 1. 정보 구조
첫 화면은 **좌우로 넘기는 가로 거리**(A안). 거리에 장소가 늘어서 있고, 가운데가 럭키빈 카페.

```
[라운지(운세)] ← [기록 보관소] ← [럭키빈 카페] → [공원(바이브)] → [지도 가게(주변 카페)] → [우체국(손님 꾸미기)]
```
- 하단 고정 바: 오늘의 그룹(아바타 3~4 겹침) + `커피내기` 버튼
- 상단: 로고, 날짜·시간, 바이브(헤드폰) 버튼
- 밤(19시~05시)엔 푸른 별밤 버전. 키리와 비둘기는 자고 있음.

## 2. 핵심 흐름 (커피내기)
```
거리 → 커피내기 → ① 게임 고르기 → ② 오늘의 손님 + 오늘 규칙 → ③ 게임 플레이
     → (턴 게임 & '한 명 진행' 꺼짐이면) 차례 넘기기
     → ④ 발표 순간 → ⑤ 영수증(자동 저장, 5초 되돌리기)
     → 한 판 더 / 이미지로 공유 / 거리로 / (선택) 주변 카페
```
- 게임 중 뒤로가기 → "이 판을 접을까요?" 확인(Exit6).
- 영수증의 "한 판 더" = 같은 손님·같은 게임으로 즉시 재시작, 기록에 `rematchOf` 연결.

## 4. 화면별 핵심 요구
### 게임 고르기 (C1)
- 맨 위 강조 카드 = 지난번 한 게임. 그 아래 5개 목록.
- 각 게임에 **🎲 운 / 🎯 실력** 뱃지 + 한 줄 설명(심리: 지목 / 내 손으로 / 구경만 / 타이밍).
- 제목 옆 "모든 게임 공통 · 15% 럭키 라운드".

### 오늘의 손님 + 오늘 규칙 (C2)
- 그룹 칩(디자인팀, 주말 모임, +새 그룹), 지난번 손님이 켜진 상태로 시작. 빠진 손님만 탭.
- `+ 게스트`: 이름만 입력, 저장 여부 선택.
- 오늘 규칙: 한 명이 진행(기본 켬) / 자비 모드(기본 끔) / 럭키 라운드 15%(항상).
- 버튼: `N명으로 시작`. 게임별 인원 범위 밖이면 비활성 + 이유 표시.

### 게임 공통 HUD
- 상단: 뒤로(44pt 원형) · 게임 이름 · `3/5 · 서준` 차례 뱃지.
- 하단: 안내 패널(시트색, 반경 20) + 이름 칩(통과/대기/차례/당첨).
- 비둘기 옆에는 항상 이름표(Jua 14). 당첨은 빨간 이름표 + 텍스트.

### 발표 (R1)
- 저녁 톤, 가로등 빛 한 줄기(블러 없음). 다른 비둘기는 좌우 날갯짓, 당첨자만 벌떡 서서 부르르.
- 럭키 라운드면 전원 날갯짓 + "오늘은 사장님이 쏩니다!".

### 영수증 (R2)
- 자동 저장 토스트 + 되돌리기(5초 카운트).
- 메뉴 줄(기본은 마지막 주문 복사) + 메뉴 고치기, 합계, **1인당 금액**, 비둘기 발자국 도장.
- 버튼 순서: `🔥 복수전! 한 판 더`(노랑, 1순위) / `이미지로 공유` / `거리로 돌아가기`.

### 주변 카페 (N1)
- MapKit 실제 지도, 내 위치, 가장 가까운 카페까지 점선 경로.
- 하단 시트 "게임 끝! 가까운 카페" 3곳(거리·도보 분·영업 여부) + 길찾기(Apple 지도로 넘김).
- 필터 칩: 지금 영업 중 / 디카페인 / 테라스(1.0은 영업 중만 실데이터, 나머지는 검색어 보정).
- 위치 권한 거부 시: 지도 대신 "동네 이름으로 찾기" 검색창.

### 바이브 (V1)
- 웹 버전 음악 기능 전부 이관: 6개 무드(카페 BGM, 재즈, 빗소리, 에스프레소 바, 타자기·벽난로, 숲). 음원은 자체 제작으로 교체(docs/03).
- 레이어 믹서(최대 3개 동시), 타이머(15/30/60분), 백그라운드 재생, 잠금화면 컨트롤.
