# 04 · 그림 파이프라인

시안 그림은 Python이 SVG를 만들고 Playwright로 PNG를 찍어 만든 **구도 확정용**이다. 앱용 본그림은 이걸 기준으로 다시 다듬는다(사용자와 합의: 본격 디자인은 개발 단계에서).

## 1. 폴더
```
art/reference/          확정 시안 PNG(2x, 780×1688). 화면 구현 시 나란히 비교
art/reference/parts/    포즈·아바타·아이콘 PNG
art/svg/pigeon/         손님 5명 × 포즈 9종 + 소품 없는 base 4종 (pigeon_{이름}_{포즈}.svg)
art/svg/kiri/           키리 포즈 12종 (뒷모습 걷기 A/B, 덥석, 옆모습들)
art/svg/icons/          게임 아이콘 6종
art/generator/          그림 생성 스크립트 (f_kit.py = 팔레트/공통 도형)
```

## 2. 캐릭터 파츠
### 비둘기 (옆모습, 발 위치가 원점, 오른쪽을 봄)
레이어 순서(뒤→앞): 뒷날개 → 꼬리(회색 띠 + 검은 끝) → 다리·발목 링 → 몸통 → 접은 날개(줄무늬 2) 또는 든 날개 → 목깃(청록 + 분홍 띠) → 머리(주황 눈, 검은 부리, 흰 콧등) → 소품.

| 손님 | 깃털 | 소품 | 발목 링 |
|---|---|---|---|
| 민수 | `#A9B2BA` 회색 | 베레모(코랄) | 코랄 |
| 지은 | `#EEEAE2` 흰색 | 리본(빨강) | 연하늘 |
| 서준 | `#B89A80` 갈색 | 목도리(머스터드) | 머스터드 |
| 하린 | `#6F7882` 먹색 | 안경 | 연청록 |
| 도윤 | `#CFC6B6` 모래색 | 모자(청록) | 피치 |

- 포즈: stand, sit, peck, flap, fly, upright(발표용 부르르), sleep, curly(꼬불 빨대 물고 퍼덕), straw(빨대 물고 날기).
- 사용자가 만드는 손님 = 깃털색(8) × 소품(10) × 발목 링(8) 조합. **런타임 합성**: 몸 파츠는 단색 템플릿(tint), 소품은 별도 레이어.
- 크기 토큰: S 1.4 / M 1.9 / L 3.0 (기준 단위 = 몸통 가로 30pt).

### 키리
- 주황 `#E8913A`, 줄무늬 `#C9722A`, 흰 부분 `#FBF2E4`. 점눈, 목띠 없음.
- 게임용: `walk_rear`(A/B 프레임 번갈아 걷기), `catch_rear`(웅크려 덥석, 비둘기는 뒤에 따로 합성).
- 거리·카페용: loaf(식빵), curl(잠), stretch, paw_tap, box_peek, sit_front 등.
- 화면 간 키리 크기는 일정하게(게임 화면 기준 높이 약 190pt).

## 3. 장면 레이어 (패럴랙스·시간대 대응)
각 장면은 최소 4장으로 나눈다: `sky` / `far`(원경 건물·나무) / `ground` / `fg`(앞 나무·화면 가장자리). 캐릭터는 그 사이에 SwiftUI로 얹는다.
- 시간대: 낮 / 저녁(발표) / 밤(별, 가로등, 잠든 캐릭터). 하늘·창문 불빛만 바꾸고 건물은 공유.
- 계절(1.1): 나뭇잎 색과 바닥 소품만 교체.

## 4. 앱에 넣는 형식
- 캐릭터·아이콘: SwiftUI `Shape`/`Path`로 옮기는 것을 기본으로(틴트·애니메이션이 쉬움). 복잡한 소품만 벡터 PDF 에셋(`Preserve Vector Data`).
- 배경: 레이어별 PNG @2x/@3x, HEIC 압축. 앱 전체 그림 용량 목표 25MB 이하(앱 총 40MB 이하).
- **SVG의 pattern/filter는 iOS 에셋에서 지원이 불안정**하다. 체크무늬 잔디, 스캘럽 지붕 같은 패턴은 SwiftUI에서 타일 이미지나 `Canvas`로 그린다.
- 손떨림 선: 패스 좌표에 미리 노이즈를 구워 넣는다(런타임 필터 금지).
- 종이 결: 전역 Metal `layerEffect` 셰이더 1개(강도 0.06), 모션 줄이기와 무관하게 유지.

## 5. 시안 다시 만들기 (선택)
```bash
cd art/generator
pip install --break-system-packages pillow   # 필요 시
python3 ios6.py && python3 kiri8.py && python3 fix6.py   # → ../../art/ios/*.html (경로는 스크립트 상단 OUT 수정)
node render.js <이름>:390:844 ...            # Playwright로 PNG 렌더
```
경로 상수(`OUT`)가 원래 작업 환경 기준이라 쓰기 전에 바꿔야 한다.
