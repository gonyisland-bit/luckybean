# 02 · 게임 규칙

1.0 = 6종. 사다리타기는 1.1.

## 0. 모든 게임 공통

### 럭키 라운드 (항상 켜짐)
- 게임 시작 시 **15%** 확률로 럭키 라운드. **두 판 연속은 없음**(직전 세션이 럭키였으면 0%).
- 게임은 평소처럼 진행되고, 발표 순간에만 뒤집힌다: 당첨자 대신 "럭키 라운드! 오늘은 사장님이 쏩니다".
- 기록: `isLuckyRound = true`, `payer = nil`. 통계에서 "럭키" 카운트로 따로 집계.
- 로스팅 룰렛에서는 통 바닥에서 이름 대신 `LUCKY PASS`가 드러나는 것으로 표현.

### 자비 모드 (기본 꺼짐, 켜면 모두에게 보임)
- **운 게임**: 최근 24시간 안에 같은 그룹에서 결제한 손님의 가중치 0.5, 나머지 1.0.
- **실력 게임**: 같은 대상의 판정 오차를 1.2로 나눠 계산하고, 화면의 초록 칸도 1.2배 넓게 그린다.
- 게임 화면 상단에 작은 `자비 모드` 칩이 계속 보인다. 몰래 켜는 방법은 없다.

### 한 명이 진행 (기본 켜짐)
- 켜짐: 차례 넘기기 화면 생략. 상단 차례 뱃지만 바뀌고 0.6초 비둘기 등장 연출.
- 꺼짐: 턴마다 차례 넘기기 화면(지붕 위 비둘기, "하린 차례", 준비됐어요 버튼).

### 한 판 더
- 영수증에서 같은 손님·같은 게임·같은 규칙으로 즉시 재시작. 새 세션의 `rematchOfID`에 이전 세션 연결.
- 기록 보관소에서 "복수전" 묶음으로 보인다. 두 판 모두 결제 기록은 각각 남는다(더블 오어 낫싱은 표시만).

### 동점
- 실력 게임 동점 → 동점자끼리만 재대결(1판, 같은 규칙). 재대결도 동점이면 무작위.

### 인원
| 게임 | 인원 |
|---|---|
| 카드품기, 로스팅 룰렛, 키리의 선택, 빨대뽑기 | 2~12 |
| 비둘기 점프, 에스프레소 마스터 | 2~8 |

## 1. 게임별 규칙

| 게임 | 분류 | 입력 | 당첨(결제)자 | 결정 시점 |
|---|---|---|---|---|
| 카드품기 | 🎲 운 | 차례인 사람이 **남의 비둘기**를 탭(지목) | 카드를 품은 비둘기의 **주인** | 시작 시 가중치로 카드 위치 결정 |
| 로스팅 룰렛 | 🎲 운 | 시작 버튼 1회(구경) | 화살표 아래 칸 바닥의 이름 | 시작 시 가중치로 결정, 회전은 그 칸에 멈추도록 역산 |
| 키리의 선택 | 🎲 운 | 없음(화면 탭 = 키리 서두름) | 키리가 덮친 비둘기 | 시작 시 가중치로 결정, 배회 경로는 연출 |
| 빨대뽑기 | 🎲 운 | 차례인 사람이 **자기 빨대**를 뽑음 | 꼬불 빨대를 뽑은 사람 | **뽑는 순간마다** 조건부 확률로 결정(아래) |
| 비둘기 점프 | 🎯 실력 | 타이밍 탭 1회, 10초 제한 | 가장 짧게 난 사람. 10초 안에 못 뛰면 즉시 당첨 | 입력 결과 |
| 에스프레소 마스터 | 🎯 실력 | 게이지 멈춤 탭 1회 | 9 BAR에서 가장 먼 사람 | 입력 결과 |

### 1-1. 카드품기
- 카페 앞 보도, 손님 수만큼 비둘기가 앉아 있다(옆모습, 자리 무작위).
- 차례인 사람은 자기 비둘기를 제외한 남은 비둘기 중 하나를 탭 → 푸드득 날아가면 그 비둘기 주인 통과.
- 카드 비둘기를 탭하면: 들썩 → 옆으로 밀려나며 카드 드러남 → 주인 결제.
- 남은 비둘기가 자기 것뿐이면 그 차례는 건너뛴다. 마지막 1마리가 남으면 자동 공개.
- 공정성: 카드 위치는 시작 시 가중치(자비 모드)로 한 번 정하므로 누가 언제 지목하든 각자의 결제 확률은 가중치 비율 그대로다.

### 1-2. 로스팅 룰렛
- 위에서 본 은색 로스터에 콩이 가득. 이름은 통 바닥에 숨어 있어 돌 때는 안 보인다.
- 칸 크기는 모두 같다(가중치는 결과 선택에만 반영, 화면에 드러내지 않음).
- 멈추면 화살표 아래 칸의 콩만 빠져 이름 공개 + 그 비둘기가 화살표 위로 날아와 앉는다.
- 회전: 3.5~5초, 마지막 1바퀴 감속(ease-out), 칸 경계마다 틱 햅틱.

### 1-3. 키리의 선택
- 카페 길 건너 공원. 비둘기들이 돌아다니며 쪼고, 키리는 뒷모습으로 네 발로 어슬렁.
- 3~6초 배회(가짜 접근 1~2회 포함) → 엉덩이 실룩 2~3회 → 덥석.
- 화면 탭 시 배회 시간 단축(최소 1.5초). 결과는 바뀌지 않는다.
- 나머지 비둘기는 깃털을 날리며 사방으로 날아간다.

### 1-4. 빨대뽑기
- 야외 테이블, 큰 아이스컵 윗부분 확대. 손님 수만큼 빨대(윗부분만 보임).
- 차례인 사람이 빨대 하나 탭 → 자기 비둘기가 물고 날아감.
- 꼬불 빨대면 끝이 걸려 날지 못하고 퍼덕 → 그 사람 결제, 게임 종료.
- **조건부 결정**: i번째 뽑는 사람 p의 꼬불 확률 = `w_p / Σ(남은 사람 w)`. 이렇게 하면 전체 결제 확률이 정확히 `w_p / Σw`가 된다(테스트로 검증할 것).

### 1-5. 비둘기 점프
- 지붕 끝에 앉은 비둘기. 타이밍 바가 왕복(1.4초 주기), 초록 칸에서 탭할수록 멀리.
- 거리(m) = `max(0.5, 9.0 - |오차| × 12.0) + 노이즈(±0.3)`, 소수 1자리. 오차 = 바 위치와 초록 칸 중심의 거리(0~1).
- 10초 안에 탭 안 하면 즉시 결제자 확정(남은 사람은 진행하지 않음).
- 자비 모드: 대상자의 오차 ÷1.2, 초록 칸 폭 ×1.2.
- 첫 플레이 1회만 코치마크.

### 1-6. 에스프레소 마스터
- 압력 게이지 바늘이 0→12 BAR를 왕복(속도는 판마다 ±15% 랜덤). 탭으로 멈춤.
- 9 BAR와의 차이가 가장 큰 사람 결제. 표시: `8.6 BAR`, 차이 `±0.4`.
- 자비 모드: 대상자의 9 BAR 차이 ÷1.2로 판정(화면에는 원래 차이 표시), 초록 칸(8.5~9.5) 폭 ×1.2, 바늘 속도는 동일.

## 2. 기록되는 것
세션마다: 날짜, 게임, 참가자 스냅샷(이름·아바타), 결제자(또는 럭키), 규칙 플래그(자비/한 명 진행), 실력 게임 점수, 영수증 항목과 합계, 1인당 금액, `rematchOfID`.

## 3. 검증 메모
- 빨대뽑기 조건부 확률은 Python으로 20만 회 시뮬레이션해 확인했다(자비 대상 0.1102 vs 기대 0.1111, 나머지 0.22±0.002).
- 로스팅 룰렛 회전 역산은 2~12명 × 칸 안 오차 ±35%에서 모두 목표 칸에 멈춤을 확인했다.
- 같은 검증이 `LuckyBeanTests/GameRulesTests.swift`에 Swift 테스트로 들어 있다. 맥에서 `⌘U`로 확인할 것.
