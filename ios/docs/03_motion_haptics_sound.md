# 03 · 모션 · 햅틱 · 소리

원칙
- 모션은 **스프링 기본**: `.spring(duration: 0.35, bounce: 0.25)`. 결과 공개만 느리게.
- 햅틱 단계: `tick`(selection) / `light` / `medium` / `heavy` / `success` / `warning`. Core Haptics 패턴은 `Haptics.swift`에 이름으로 등록.
- 모션 줄이기(`accessibilityReduceMotion`) 켜짐: 화면 셰이크·흔들림·반복 실룩 제거, 페이드로 대체. 햅틱은 유지.
- 소리는 모두 자체 제작. 무음 모드에선 효과음 끔, 바이브(음악)는 사용자 설정 따름.

## 자체 제작 음원 목록
### 바이브(앰비언트, 루프 2~4분, 이음매 없이)
| 키 | 무드 | 구성 레이어 |
|---|---|---|
| `vibe.cafe` | 럭키빈 카페 | 웅성거림, 컵 부딪힘, 스팀 |
| `vibe.jazz` | 느긋한 일요일 재즈 | 피아노 + 브러시 드럼(직접 작곡) |
| `vibe.rain` | 비 오는 창가 | 빗소리, 먼 천둥, 창 빗방울 |
| `vibe.espresso` | 아침 바리스타 | 그라인더, 추출, 스팀 |
| `vibe.writer` | 마감 작가 | 타자기, 벽난로 |
| `vibe.forest` | 숲 산책 | 새소리, 시냇물 |

- 웹 버전 `sounds/*.mp3`는 출처 확인 전까지 앱에 넣지 않는다. 자체 제작본으로 교체.
- 앰비언트는 레이어별 파일(48kHz, AAC 256k)로 두고 AVAudioEngine에서 믹싱 → 사용자가 레이어 볼륨 조절.
